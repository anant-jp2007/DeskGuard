# Report a duplicate card charge

## Report two completed payments for one purchase

If both charges for the same purchase show Completed, open Activity, select one charge, and choose Report a problem > Charged twice. Include the merchant, the receipt if available, and the references for both charges.

## Check whether one of the charges is pending

Open both entries in Activity and compare their statuses. If one entry is pending, check whether it clears or disappears before reporting two completed charges.
